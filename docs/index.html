rpt2frx

Convert Crystal Reports (.rpt) into FastReport templates (.frx) with one command. Free beta for Windows.

Download the beta installer
Windows 10/11 64-bit · version 0.1.0-beta.1 · everything runs on your PC, nothing is uploaded
Requires the SAP Crystal Reports runtime. rpt2frx reads .rpt files through the free 64-bit SAP Crystal Reports runtime engine for .NET Framework, which you install separately from SAP. The installer checks for it and shows you where to get it. Converting an existing .metadata.json file does not need it.

What it does

rpt2frx reads a report's design only (sections, fields, groups, totals, formulas, formatting; no data) and writes a FastReport template that you open and finish in the free FastReport designer.

Quick start

rpt2frx --version
rpt2frx doctor
rpt2frx "C:\Reports\Sales.rpt" --preview

This writes Sales.frx next to the report, plus Sales.preview.pdf and PNG pages with sample data so you can check the layout. Open a new terminal after installing so the command is found. You can also right-click a .rpt file and choose Convert with rpt2frx, or run rpt2frx with no arguments for a guided menu.

Install

  1. Download rpt2frxSetup-0.1.0-beta.1.exe from the Releases page.
  2. Run it. The beta installer is not code-signed yet, so Windows may say unknown publisher: choose More info, then Run anyway.
  3. Read the system-check page. It tells you if the SAP runtime or .NET Framework 4.8 is missing and how to get it.
  4. Keep Add rpt2frx to PATH ticked.
Verify your download (optional). Expected SHA-256:

Known limits (beta)

AreaStatus
Logos / picturesImage data is not exported. Use --picture logo.png.
FormulasCommon ones convert (If/Then/Else, running totals, sums). Some functions such as propercase, towords, left are not translated and are listed as warnings.
Subreports, charts, cross-tabsNot converted yet; reported as warnings.
LayoutClose to the original, not pixel-identical. Always review the result.
