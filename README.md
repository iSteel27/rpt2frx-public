# rpt2frx

Convert Crystal Reports (`.rpt`) into FastReport (`.frx`) templates. Windows, free beta.

- Download: see [Releases](../../releases/latest)
- Guide: [docs/GETTING-STARTED.md](docs/GETTING-STARTED.md)
- Feedback / bugs: [open an issue](../../issues/new/choose)
- Beta terms: [BETA-TERMS.md](BETA-TERMS.md) · Third-party notices: [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)

Requires the free 64-bit SAP Crystal Reports runtime, installed separately. This repository holds the site, documentation and release downloads only.
